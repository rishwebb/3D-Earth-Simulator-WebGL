# 🌍 3D Earth Simulator with WebGL & Orbital Physics

[![Three.js](https://img.shields.io/badge/Three.js-r128%2B-black.svg)](https://threejs.org/)
[![WebGL](https://img.shields.io/badge/Graphics-WebGL%202.0-orange.svg)](https://www.khronos.org/webgl/)
[![CSS3](https://img.shields.io/badge/UI-Aero%20Glassmorphism-blue.svg)](https://github.com/rishwebb)

**3D Earth Simulator** is a high-fidelity 3D Earth simulator rendering photorealistic planetary textures, dynamic atmospheric Ray-tracing scattering, procedural cloud layers, and real-time day/night terminator transitions.

---

## 🚀 Launching
Clone and launch with any static web server:
```bash
git clone https://github.com/rishwebb/TerraSphere-3D-Earth-Simulator.git
cd TerraSphere-3D-Earth-Simulator
npx serve .
```
